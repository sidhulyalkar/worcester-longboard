# Worcester X1

Experimental off-road electric mountainboard / longboard platform focused on controllability, instrumentation, redundant braking, and terrain-aware ride control.

> **Status:** early engineering prototype. Hardware and firmware in this repository are not yet qualified for riding. Begin with an unpowered rolling chassis and bench validation.

Development is staged through reviewed feature branches. The first implementation tranche is `feat/x1-alpha-v0.1`.
